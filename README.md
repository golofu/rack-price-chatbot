# แชทบอทราคาแร็คพวงมาลัย

**เปิดใช้งานทันที:** [https://rack-price-chatbot.vercel.app](https://rack-price-chatbot.vercel.app)

ผู้ช่วยตอบราคาแร็คพวงมาลัยสำหรับพนักงานหน้าร้านอะไหล่ พิมพ์คำถามภาษาไทยหรืออังกฤษ ระบบตอบราคาพร้อมบอกว่ารหัสแร็คตัวนั้นใช้ร่วมกับรถรุ่นไหนได้อีก

หน้าเว็บทั้งหมดอยู่ในไฟล์ `index.html` ไฟล์เดียว ไม่มี backend ไม่ใช้ API key ไม่เรียก network ตอนใช้งาน (ยกเว้นโหลดฟอนต์จาก Google Fonts) เปิดจากไฟล์ในเครื่องก็ทำงานได้

> ข้อมูลในชุดนี้เป็นราคาสมมติสำหรับฝึกอบรม ไม่ใช่ราคาขายจริง

## ถามได้แบบไหนบ้าง

| แบบ | ตัวอย่าง |
|---|---|
| ชื่อรุ่น ไทย/อังกฤษ | `แร็ค vigo ราคาเท่าไหร่` · `ราคาแร็ควีโก้เท่าไหร่` · `ดีแม็ก 4wd` |
| รุ่น + ปี | `altis 2010` · `ไทรทัน 2018` |
| รหัสแร็ค | `RT01 ใช้กับรถอะไรได้บ้าง` |
| ประเภท + งบ | `แร็คไฟฟ้าไม่เกิน 2800` · `แร็คโตโยต้าถูกสุด` |
| รหัสเครื่องยนต์ | `เครื่อง 2KD ใช้แร็คตัวไหน` |
| นับจำนวน | `อีซูซุมีกี่รายการ` |

คำตอบจับกลุ่มตามรหัสแร็ค ไม่ใช่รายแถว เพราะหน้าเคาน์เตอร์ต้องรู้สองอย่างพร้อมกัน คือราคา และรหัสนี้ใส่รถอะไรได้อีก แถวที่ขีดเส้นสีเน้นคือรุ่นที่ตรงกับคำถาม แถวอื่นในการ์ดเดียวกันคือรุ่นที่ใช้แร็ครหัสเดียวกันได้

## โครงสร้าง

```
index.html                    หน้าเว็บที่ deploy (ไฟล์ generate ห้ามแก้มือ)
data/rack-price-list-200.xlsx ข้อมูลต้นทาง แก้ราคา/เพิ่มรุ่นที่นี่
build/template.html           ต้นแบบหน้าเว็บ + ตรรกะบอท (แก้ UI/ตรรกะที่นี่)
build/build.py                ประกอบ template + data + logo -> index.html
build/seed_pricelist.py       ตัวสร้างข้อมูลสมมติ 200 แถว (ใช้ครั้งแรกครั้งเดียว)
build/logo-gen-ai-space.png   โลโก้ ฝังเป็น data URI ตอน build
```

## แก้ข้อมูลแล้ว build ใหม่

```bash
pip install openpyxl pillow
python build/build.py
```

`build.py` จะตรวจข้อมูลให้ก่อนเขียนไฟล์ ถ้าหัวตารางผิดลำดับ ประเภทแร็คสะกดไม่ตรง หรือปีไม่อยู่ในรูป `YYYY-YYYY` จะหยุดพร้อมบอกเลขแถวที่ผิด

กติกาของ `data/rack-price-list-200.xlsx`

- หัวตารางต้องเรียงแบบนี้เป๊ะ: ลำดับ, รหัสแร็ค, BRAND, MODEL, ปี, เครื่องยนต์, ประเภทแร็ค, ราคาขาย (ร้านอะไหล่)
- ประเภทแร็คใช้ได้ 2 ค่า: `น้ำมัน` กับ `ไฟฟ้ากระบอกแห้ง`
- ปีใช้รูป `2005-2011`
- รุ่นพวงมาลัยซ้ายต่อท้ายชื่อรุ่นว่า `*พวงมาลัยซ้าย*`
- รหัสแร็คเดียวกันต้องราคาเดียวกันและประเภทเดียวกันทุกแถว

## Deploy

Vercel เป็น static site ไม่ต้องตั้ง build command

```bash
npx vercel --prod
```

`vercel.json` ตั้ง `cleanUrls` และ security header ไว้แล้ว

## เพิ่มคำเรียกรุ่นภาษาไทย

ถ้าพนักงานพิมพ์ชื่อรุ่นแบบที่บอทไม่รู้จัก เพิ่มใน `MODEL_ALIAS` ใน `build/template.html` แล้ว build ใหม่ เช่น

```js
'ฟอร์จูนเนอร์':'fortuner', 'ดีแม็ก':'d-max',
```

ยี่ห้อเพิ่มที่ `BRAND_ALIAS` ด้วยรูปแบบเดียวกัน
